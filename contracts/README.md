# Contracts

The only code-level things shared between services.

- `openapi/` holds the OpenAPI 3 files. `gateway.yaml` is generated by drf-spectacular (`python manage.py spectacular --file ../contracts/openapi/gateway.yaml`); `simulator.yaml` the same from the simulator.
- `events/` holds JSON Schemas for merchant notifications: `payment.authorised`, `payment.declined`, `payment.blocked`, `payment.unresolved`, `payment.captured`, `payment.cancelled`, `refund.completed`, `refund.failed`. Each carries an event ID, a per-payment sequence number and a signed timestamp.
- `generated/` holds TypeScript types generated from the OpenAPI files for the frontends.

Do not share the payment state-machine code between the gateway and the simulator, so independent tests can catch a defect in either.
